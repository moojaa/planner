# 주말 플랜 ✨

호치민 주말 나들이 플랜 모음 (모바일 웹 + PDF).

## 구성
- `index.html` — 모바일 웹앱 (탭: 서커스 / 동물원 A·B, 🇰🇷↔🇻🇳 언어 전환, 식당·카페·영화관 구글맵 링크)
- `pdf/` — 같은 내용의 PDF 6종 (서커스 / 동물원A / 동물원B × 한국어·베트남어)

## 보기
`index.html`을 브라우저에서 열면 됩니다. 비밀번호 입력 후 진입.

## 배포 (Netlify)
- **Netlify Drop**: https://app.netlify.com/drop 에 폴더 드래그
- **GitHub 연동**: repo push 후 Netlify에서 Import → Deploy (루트의 `index.html` 자동 서빙)
